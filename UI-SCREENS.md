# Zxsite UI screen map

The student site is designed mobile-first and follows the supplied Quizard-style references while keeping the brand as **Zxsite**.

## Screen 01 — Home
- Green gradient hero with Zxsite logo and tagline.
- Hamburger button with notification dot.
- Rounded blue-outlined batch search.
- Large category cards:
  - Boards Level Tests
  - JEE Tests
  - NEET Tests
  - Dropper Tests
  - Other Batch Tests
- Floating `Join us` pill and Telegram button.

## Screen 02 — Expanded category
- Category card opens inline.
- Batch rows show batch name, access type and test count.
- Chevron rotates when expanded.

## Screen 03 — Search results
- Search query is reflected in the page heading.
- Results show batch name, category and number of tests.
- Tapping a result opens the batch page.

## Screen 04 — Batch test series
- Batch banner with Free/Premium status.
- Test-series count.
- Search inside the batch.
- Test cards with questions, duration and date.
- `Instructions` and `Start Test` actions.

## Screen 05 — Instructions
- Test title and pre-test rules.
- Questions / duration / date summary.
- Full-width start button.

## Screen 06 — Test attempt
- Exam bar with question count and timer.
- Multiple-choice questions.
- Submit Test action.

## Screen 07 — Side menu
- Test Series (NEW)
- DPP's
- Login
- Sign Up
