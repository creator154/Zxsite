# PrepDesk

Demo exam-prep platform (NEET / JEE / Boards / DPP) with your own placeholder content.

## Run locally
npm install
npm start
Then open http://localhost:3000

## Deploy to Heroku
heroku login
heroku create your-app-name
git init
git add .
git commit -m "initial"
git push heroku main

## Replace content
Edit the DATA object inside public/index.html (categories, batches, test series, sample questions).
